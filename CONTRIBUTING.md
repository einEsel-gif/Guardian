# Contributing

Use Java 25. Run `mvn clean verify` and build the client with its Gradle wrapper before opening a PR.

Keep code, comments and messages in English. Explain what changed and how you tested it. For detection rules, include evidence and avoid broad filename matches.

Test connections with a clean client, a missing Guardian mod, a blocked mod and a failed scan. Check concurrent connections too. Do not include player data or cheat binaries in reports.
